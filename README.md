# 🎰 iGaming Risk & Fraud Command Center

An interactive Business Intelligence and behavioral risk analysis dashboard built to monitor high-frequency online gaming and betting platforms, detect exploitation hot spots, and flag malicious actor clusters.

---

## 🚀 Project Overview
In fast-paced iGaming and sports betting ecosystems, early identification of automated bot syndicates and rapid-fire script activity is critical for mitigating financial exposure. This project bridges the gap between raw backend telemetry and clear executive storytelling.

* **Data Processing & Feature Engineering:** Python (Pandas)
* **Data Visualization & BI:** Tableau Public [View Interactive Dashboard](https://public.tableau.com/authoring/iGamingFraudRiskBIAnalyticsEngine/Dashboard1#2)

---

## 📊 Core Architecture & Features
1. **Executive Command KPIs:** High-level operational metrics tracking total transaction volume ($15,000$), cumulative risk scores ($461,855$), and high-risk security alerts ($2,315$).
2. **Vertical Exploit Monitor:** Aggregated risk across casino verticals and game titles (such as *Baccarat Speed*, *Blackjack VIP*, and *NBA Totals*) to pinpoint vulnerability hot spots.
3. **Behavioral Social Clusters:** Isolated top high-risk device IDs (`DEV_100` through `DEV_139`) mapped against precise player typologies (ranging from automated bot operators to syndicated members).

---

## 🛠️ Technical Workflow
- **Data Ingestion & Hygiene:** Handled incoming simulated telemetry, removed record anomalies, and structured multi-variable log files.
- **Risk Scoring Logic:** Engineered weighted cumulative risk metrics to flag abnormal velocity and betting behaviors.
- **Executive Presentation:** Designed custom multi-layer dashboard containers with traffic-light color mapping to optimize data hierarchy for triage teams.
